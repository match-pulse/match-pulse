# MatchPulse

MatchPulse is a web application for managing football tournaments and letting participants predict match results. Participants earn points based on their predictions and compete in a tournament leaderboard.

## Features

- Create and manage tournaments, matches, and results.
- Submit match predictions before kickoff.
- Award points based on prediction accuracy.
- Track standings across a tournament.
- View prediction statistics and match-related data.

## Project Status

Early-stage development. Requirements and architectural decisions are being defined, with an initial focus on tournament management, match predictions, scoring, and standings.
