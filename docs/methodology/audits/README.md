# Audit Reports

Permanent, dated software audit reports.

- Naming: `<YYYY-MM-DD>-<issue>-<slug>.md`.
- Template: [`audit-report-template.md`](../../workflows/templates/audit-report-template.md).
- Index: [`docs/methodology/README.md`](../README.md).
- Findings: register every finding in [`findings-register.md`](../findings-register.md).
- Rules: audits are read-only; the report is never overwritten. Corrections are dated addenda. A superseded report keeps its original and links forward.
