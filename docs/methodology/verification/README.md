# Verification Records

Permanent, dated verification evidence.

- Naming: `<YYYY-MM-DD>-<issue>-<slug>.md`.
- Template: [`verification-record-template.md`](../../workflows/templates/verification-record-template.md).
- Index: [`docs/methodology/README.md`](../README.md).
- Rules: record the exact command, environment, observed result, and limitations. Never record an unrun check as passed. Failed and unverified results are preserved. The record is never overwritten; corrections are dated addenda.
