## 3. Defects found and fixed during verification

1. **Server-action redirects were caught as errors.** The success path called `redirect()` inside a `try`, so the `catch` converted every successful mutation into an error redirect. Refactored all v3 actions to use an `attempt()` result and redirect after the try/catch.
2. **Home routing sent the organizer fixture to the club dashboard.** The organizer fixture now owns the demo club. Reordered routing so legacy `ORGANIZER`/`CLUB` roles keep their paths, while new fan-owned clubs go to `/club/dashboard`.
3. **Select contrast.** Native selects with `text-black` inherited the dark page background and produced a 1.04:1 contrast ratio. Added `bg-white` to the new form controls.
4. **Smoke test label.** The smoke test still looked for “Continue as fan”; updated to the new “Fan email” control.
5. **Strict locator.** The fan test matched “E2E Fan” in several places; scoped the assertion to the ticket article.

## 4. Limits

- No real payments, financial KYC, hosted deployment or production recovery is claimed.
