# Refactor Assessments

Permanent, dated refactoring assessments.

- Naming: `<YYYY-MM-DD>-<issue>-<slug>.md`.
- Template: [`refactor-assessment-template.md`](../../workflows/templates/refactor-assessment-template.md).
- Index: [`docs/methodology/README.md`](../README.md).
- Findings: register every finding in [`findings-register.md`](../findings-register.md).
- Rules: assessments are read-only; observable behavior must be preserved. The assessment is never overwritten. Corrections are dated addenda. A superseded assessment keeps its original and links forward.
