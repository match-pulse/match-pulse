# Incident Reports

Permanent, dated incident reports.

- Naming: `<YYYY-MM-DD>-<slug>.md`.
- Template: [`incident-report-template.md`](../../workflows/templates/incident-report-template.md).
- Index: [`docs/methodology/README.md`](../README.md).
- Follow-up: register recurring or unresolved issues in [`findings-register.md`](../findings-register.md).
- Rules: reports are never overwritten. Corrections are dated addenda. A superseded report keeps its original and links forward. Do not include credentials or unnecessary sensitive data.
