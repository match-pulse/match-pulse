# Remediation Records

Permanent, dated remediation plans and closure records.

- Naming: `<YYYY-MM-DD>-<issue>-<slug>.md`.
- Template: [`remediation-plan-template.md`](../../workflows/templates/remediation-plan-template.md).
- Index: [`docs/methodology/README.md`](../README.md).
- Findings: link the `FND-NNN` identifiers from [`findings-register.md`](../findings-register.md).
- Rules: remediation is approved before implementation. The record is never overwritten. Corrections are dated addenda. Closure requires verification evidence and cannot be certified by the implementer alone.
