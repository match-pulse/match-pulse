# Course Submission Package

The Markdown sources are authoritative. The PDFs are dated renders generated by
`bun run docs:pdf`.

## Regeneration

```bash
bunx playwright install chromium
bun run docs:pdf
```

The script converts Markdown to HTML with `marked` and prints it to PDF with
Playwright Chromium. It writes the submission PDFs into this directory.

## What the package contains

- A one-page kata with broad R1–R8 requirements; detailed R1.1–R8.x requirements
  are in [`../architecture/requirements.md`](../architecture/requirements.md).
- A two-page characteristics document with selection, traceability and quantified
  targets; evidence is linked, not reprinted.
- A three-page architecture description with a 3-minute walkthrough, modules, key
  decisions, compact code references and limits.
- Five one-page checkpoints. Each checkpoint is about three minutes.
- No hosted deployment, real payments, real-user validation or independent
  third-party audit. The limits are stated in the documents.

## Detail

The full C4 views, code map, ADRs, verification records, findings register and AI
transparency log remain in the repository. The submission documents link to them.
